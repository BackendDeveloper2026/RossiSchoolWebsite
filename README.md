# Rossi School — Sito Web

Sito web istituzionale realizzato per **Rossi School**, ente di formazione professionale con sede a San Vitaliano (NA).

Il progetto è stato sviluppato con tecnologie web native, con particolare attenzione a semplicità, velocità, responsive design e facilità di pubblicazione.

## 🌐 Demo

👉 **[Visualizza la demo del sito](https://backenddeveloper2026.github.io/RossiSchoolWebsite/)**

---

## 📋 Descrizione

Il sito presenta Rossi School e la sua offerta formativa attraverso una struttura moderna e intuitiva.

L'obiettivo è fornire una presenza online professionale e facilitare il contatto con potenziali studenti, professionisti e aziende.

### Sezioni principali

- Presentazione di Rossi School
- La nostra missione
- Offerta formativa
- Perché scegliere Rossi School
- Call to action
- Contatti
- Modulo di richiesta informazioni

---

## ✨ Funzionalità

- Design moderno e professionale
- Layout completamente responsive
- Ottimizzazione per smartphone, tablet e desktop
- Navigazione semplice e intuitiva
- Sezione dedicata all'offerta formativa
- Informazioni di contatto
- Collegamento a Google Maps
- Collegamento alla pagina Facebook
- Modulo di contatto
- Validazione dei campi
- Protezione antispam tramite honeypot
- Messaggio di conferma dopo l'invio
- Contatore caratteri per il messaggio
- Gestione degli errori di invio
- Integrazione con API esterna per la gestione dei contatti

---

## 🛠️ Tecnologie utilizzate

- **HTML5**
- **CSS3**
- **JavaScript**
- **Web3Forms API**
- **Google Maps**
- **GitHub Pages**

Il progetto non richiede un backend proprietario per il funzionamento del sito.
